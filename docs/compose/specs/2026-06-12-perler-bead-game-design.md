# 拼豆工坊 iOS 游戏设计文档

## [S1] 背景与目标

做一款 iOS 拼豆（Perler Beads / Fuse Beads）休闲小游戏，核心体验是：

1. **数字填色**：按编号把虚拟拼豆放到对应格子，完成图案。
2. **自由创作**：在网格上自由选色、绘制自己的图案。
3. **图片转拼豆**：把相册照片或拍照转成拼豆底图，既可以按自动提取的颜色填，也可以按自己喜欢的颜色自由改。

最终完成品要像真实拼豆挂件一样展示，支持保存、分享。

## [S2] 方案概述

| 模块 | 方案 |
|------|------|
| 技术栈 | Swift + SwiftUI，本地优先（UserDefaults / Core Data），预留云端扩展 |
| 视觉 | 轻度拟物：圆角珠 + 内阴影 + 顶部高光；未填色格带 pegboard 细孔洞纹理 |
| 珠粒尺寸 | 5mm 标准（默认）、2.6mm Mini（精细）、10mm Biggie（低龄/大颗粒） |
| 图片转拼豆 | 用户选图 → 选珠粒尺寸/网格尺寸/颜色数 → 预览 → 生成底图 |
| 颜色模式 | 「真实模式」映射到内置拼豆色板；「自由模式」可任意改色 |
| 填色交互 | 默认单点，长按切换拖拽连填；双指缩放/平移 |
| 完成展示 | 熨烫压平动画 → 带挂环/卡片底板/阴影的成品展示 |

## [S3] 视觉风格

### 3.1 拼豆格子

- 形状：圆角方块（圆角半径约为边长 15%–20%）。
- 已填色：填充颜色 + 1px 内阴影（底部略深）+ 顶部小高光，模拟塑料珠轻微凸起。
- 未填色：浅灰背景，带细孔洞纹理（pegboard 孔），填色后孔洞弱化。
- 数字填色：格子中央显示浅色编号，完成/切换视图后可隐藏编号。

### 3.2 画布与 pegboard

- 画布背景模拟灰色 pegboard，网格线仅在放大或编辑模式下 subtle 显示。
- 不同珠粒尺寸下，格子视觉大小不同：Biggie 大、Mini 小，但屏幕适配优先保证可点击。

### 3.3 完成品展示

- 触发「熨烫」动画：所有珠子轻微压平、高光减弱、边缘融合。
- 完成后套入白色卡片底板，上方加金属挂环，整体带柔和投影。
- 分享图可导出为 1:1 正方形或手机壁纸尺寸。

## [S4] 图片转拼豆底图

### 4.1 导入

- 入口：主菜单「图片转拼豆」、关卡/自由创作内的导入按钮。
- 来源：相册选图、拍照。
- 权限：首次使用时请求 Photos / Camera 权限。

### 4.2 转换参数

| 参数 | 可选项 |
|------|--------|
| 珠粒尺寸 | 5mm 标准（默认）、2.6mm Mini、10mm Biggie |
| 网格尺寸 | Biggie 8×8–16×16；标准 10×10–48×48；Mini 16×16–64×64 |
| 颜色数量 | 4 / 8 / 16 / 24 / 自定义滑块 |
| 模式 | 真实模式 / 自由模式 |

网格尺寸默认值与珠粒尺寸联动：标准默认 24×24，Mini 默认 32×32，Biggie 默认 12×12。

### 4.3 预处理

- 对原图做缩放、亮度/对比度/边缘增强的实时预览。
- 真实模式：用 k-means 或中位切分提取指定数量颜色，再映射到内置拼豆色板的最近色。
- 自由模式：提取原图主色作为默认参考色，但允许玩家后续任意修改每个格子的颜色。

### 4.4 生成结果

- 生成后进入填色界面：
  - 真实模式 → 数字填色界面（带颜色编号与调色板）。
  - 自由模式 → 自由创作界面（原图主色作为初始图案，玩家可改色）。

## [S5] 填色交互

### 5.1 默认单点

- 点按空白格：填入当前选中的颜色。
- 点按已填色格：
  - 若颜色与当前选中一致：清除该格。
  - 若不一致：覆盖为当前选中颜色。

### 5.2 拖拽连填

- 长按调色板按钮或长按画布进入拖拽模式。
- 手指划过的连续空白格自动填入当前颜色；若划过已填色格且颜色与当前选中不同，也覆盖为当前颜色。
- 松手后：
  - 默认退出拖拽模式（适合一次性大面积填充）。
  - 可在设置中改为保持拖拽模式，需再次点击关闭。

### 5.3 画布操作

- 双指捏合：缩放画布（范围 0.5×–4×）。
- 单指拖动：平移画布。
- 双击：还原到 1× 并居中。

### 5.4 工具栏

- 底部固定工具栏：撤销、重做、清空、保存、完成。
- 撤销/重做支持手势：shake-to-undo。
- 调色板在工具栏上方，可横向滚动，当前选中颜色高亮。

### 5.5 完成与展示

- 所有格子填完后，点击「完成」触发熨烫动画。
- 动画：珠子从轻微凸起压平，内阴影变浅，相邻同色珠子边缘融合。
- 动画结束后进入成品展示页，显示：
  - 作品图（带挂环+卡片底板）。
  - 信息：网格尺寸、颜色数、耗时。
  - 操作：保存到相册、分享、再做一次。

## [S6] 游戏模式

### 6.1 关卡模式

- 内置图案库，按主题分类：热门 IP、萌宠、食物、文字梗等。
- 每个关卡标注难度（简单/中等/困难）和网格尺寸。
- 完成后解锁下一关或获得金币/奖励。

### 6.2 自由创作

- 空白网格，玩家自由选色、绘制。
- 支持导入图片作为底图参考。
- 可保存到「我的作品」。

### 6.3 图片转拼豆

- 见 [S4]。

### 6.4 每日挑战

- 每天推送一个限时图案。
- 完成后获得额外奖励或成就。

## [S7] 数据与存储

### 7.1 本地存储

- 用户作品：`CanvasState` 序列化到本地文件（JSON 或 Core Data）。
- 设置：UserDefaults。
- 关卡进度：UserDefaults。

### 7.2 数据结构

```swift
struct CanvasState: Codable {
    let id: UUID
    let width: Int
    let height: Int
    let beadSize: BeadSize        // .standard / .mini / .biggie
    let mode: CanvasMode          // .numbered / .free
    let colorPalette: [BeadColor]
    let cells: [[Int?]]           // 颜色索引，nil 表示未填色
    let createdAt: Date
    let updatedAt: Date
}

struct BeadColor: Codable {
    let id: Int
    let name: String?
    let hex: String
    let isRealBead: Bool          // 是否对应真实拼豆颜色
}
```

### 7.3 内置素材

- 关卡图案 JSON：包含名称、分类、难度、网格尺寸、颜色索引矩阵。
- 拼豆色板 JSON：48 色基础色板 + 扩展色，含名称与 HEX。

## [S8] MVP 范围

第一阶段只实现核心闭环：

1. 主菜单 + 自由创作 + 图片转拼豆。
2. 三种珠粒尺寸 + 标准网格尺寸范围。
3. 真实模式/自由模式颜色系统。
4. 单点 + 拖拽填色、撤销/重做、缩放平移。
5. 完成动画 + 成品展示 + 保存到相册。

暂不实现：

- 关卡模式、每日挑战、成就、商店、广告、云端同步。
- 复杂 3D 拼豆结构。
- 社交分享平台（仅调用系统分享）。

## [S9] 后续待确认

2. 图片转拼豆的颜色量化算法是本地实现还是调用云端模型？
3. 是否需要在填色界面显示「剩余未填格子数」和「预计耗时」？
4. 分享图是否需要包含品牌水印或 #拼豆工坊 标签？
