## [S1] 背景与目标

做一款 iOS 拼豆（Perler Beads / Fuse Beads）休闲小游戏，核心体验是：

1. **自由创作**：在网格上自由选色、绘制自己的图案（内联尺寸选择：16×16 简易 / 29×29 标准默认）。
2. **导入图片生成拼豆模板**：从相册选择一张照片，自动裁剪、降采样、量化为可摆放的拼豆图纸（16/24/32/48，默认 32×32）。
3. **图纸复刻**（示例/调试内容）：选择内置图纸，在半透明引导下精确摆放拼豆。
4. **熨烫成品**：完成摆放后进行熨烫模拟，生成可展示的成品。
5. **作品库与分享**：保存作品到本地图库，生成高清分享图。

最终完成品支持多种展示类型（冰箱贴、钥匙扣、挂件），可拖动旋转查看，并导出分享图。

## [S3] 视觉与交互风格（当前实现）

- **工作台**：16×16 标准网格（可配置），使用 3D 珠子 + Pegboard 表面。
- **工具**：
  - **Tweezers**：拾取珠子、拖拽、吸附到网格、弹跳放置效果。
  - **Eraser**：擦除已放置珠子。
  - **Iron**：拖拽熨斗进行热量模拟。
- **图纸引导**：半透明底图，可开关；可开启「错误格提示」（错色或缺失）。
- **熨烫动画**：基于热量的渐进压平、边缘融合、烧焦风险。提供 IroningStats（平均熔化、粘连、峰值热量、烧焦程度）。
- **成品查看**：作品脱离 pegboard，干净背景 + 3D 拖拽旋转。
- **调试**：内置 DebugOverlay（F1 显示 FPS，反引号打开测试面板）。

## [S4] 核心流程（Vertical Slice）

```
主菜单
├── 自由创作（内联尺寸选择 16×16 / 29×29） → 摆豆 → 熨烫 → 成品查看 → 保存/分享
├── 导入图片生成模板 → 选照片 → 预览+选尺寸 → 摆豆 → 熨烫 → 成品 → 保存/分享
├── 示例图纸（次级链接，即原「图纸复刻」）→ 选择图纸 → 带引导摆豆 → 熨烫 → 成品 → 保存/分享
└── 作品库   → 浏览本地作品 → 重新打开编辑或查看
```

**图片导入管线**（`PhotoImportService` → `PhotoToPatternConverter`）：
1. 选图：iOS 真机/模拟器使用原生 `PHPickerViewController`；Unity Editor 用本地文件选择框；其余平台回退到程序化占位纹理。
2. 居中裁剪为正方形，按目标网格尺寸盒式降采样（每格取平均色，而非单点采样）。
3. 平均透明度低于阈值的格子留空；其余格子在现有 8 色色板中取最近色（`BeadPaletteRepository.FindNearestColor`）。
4. 确认后作为 `WorkshopSession`（`PatternSource.Imported`）进入工作台，可继续手动调整。

**内置图纸**（5 个，示例/调试内容）：
- heart（爱心）
- star（星星）
- guofeng_cloud（国风云纹）
- milk_tea_cup（奶茶杯）
- support_sign（应援字牌）

**熨烫结果**：UnderIroned / Good / OverIroned / Burned 等，通过 IroningResult 表示。

## [S5] 数据与存储（当前）

- 色板：`bead_palette.json` + BeadPaletteRepository
- 图纸：BuiltinPatternFactory + PatternRepository（BeadPatternData）
- 作品存档：FinishedWorkRecord + GalleryRepository（JSON 索引 + PNG 缩略图）
  - 路径：`Application.persistentDataPath/gallery/`
- 分享图：ShareCaptureService 生成 1080×1920 图片，保存到 `persistentDataPath/shares/`

## [S6] MVP 范围（当前已交付）

已完整实现：
- 主菜单（自由创作 + 导入图片生成模板 + 作品库，图纸复刻降级为次级示例入口）
- 图片导入管线：原生 PHPicker 选图 → 裁剪/降采样/量化 → 预览 → 确认进入工作台
- 两种珠粒尺寸 + 可变网格尺寸（自由创作 16/29，导入 16/24/32/48）+ 按网格自适应取景的相机
- 三种工具 + 高级熨烫模拟 + 视觉反馈（放置弹跳、熨烫热区、结果/成品出现动画）
- 3 种成品类型 + 3D 查看 + 保存到本地作品库 + 保存到系统相册 + 高清分享图（带水印）
- 统一暖色调 UI 主题（程序化圆角精灵），覆盖主菜单/导入/图纸选择/作品库/成品查看/图纸引导/熨烫界面
- iOS 模拟器与真机导出支持（Editor 工具 + build-ios-simulator.sh / build-ios-device.sh），
  自动写入相册权限描述并链接 PhotosUI/Photos 框架
- 本地持久化

**首版明确不做**（见 BeadWorksUnity/README）：
- 关卡模式、每日挑战、成就、广告、内购、云端共创
- Biggie 尺寸（10mm）
- 复杂 3D 结构
- 图片导入的多图/批量选择（当前限单张）
