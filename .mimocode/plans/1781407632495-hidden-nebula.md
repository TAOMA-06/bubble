# 拼豆工坊 — 真实拼豆外观优化 ✅

## 概述

优化拼豆的外观，使其更像真实的 Perler 拼豆。真实拼豆特征：
- **圆柱形立体感**：边缘凸起，有明显的厚度感
- **中心孔洞**：贯穿的圆孔，边缘有倒角
- **塑料光泽**：表面光滑，有高光和反射
- **颜色渐变**：从中心到边缘有轻微的色彩变化

---

## 修改文件 ✅

#### `BeadWorks/Views/Components/BeadCell.swift` ✅
当前实现问题：
- 高光只是简单的白色椭圆
- 中心孔洞太小且无立体感
- 缺少边缘厚度感

改进方案：
1. **底部阴影**：添加椭圆形底部阴影，模拟立体感
2. **边缘厚度**：使用多层 Circle 叠加，创建边缘凸起效果
3. **中心孔洞**：
   - 增大孔洞尺寸（size * 0.28）
   - 添加孔洞边缘的倒角效果（渐变）
   - 孔洞内部添加深度感（深色渐变）
4. **表面光泽**：
   - 使用 RadialGradient 模拟塑料材质
   - 高光位置偏移（左上角），模拟光源方向
   - 添加 secondary highlight（右下角微弱反光）
5. **边缘描边**：
   - 外圈使用深色描边
   - 内圈使用浅色描边，模拟边缘凸起

#### `BeadWorks/Views/BeadGridView.swift` (Canvas 绘制部分) ✅
同步更新 Canvas 绘制逻辑，与 BeadCell.swift 保持一致：
1. 绘制顺序：
   - 底部阴影（最底层）
   - 主体圆形
   - 边缘厚度层
   - 中心孔洞（带倒角）
   - 表面高光
   - 边缘描边
2. 使用 `context.drawLayer` 来管理混合模式
3. 对于小尺寸（cellSize < 10），简化细节以保持性能

## 具体实现细节

### BeadCell.swift 修改

```swift
// 1. 底部阴影（最底层）
Ellipse()
    .fill(Color.black.opacity(0.2))
    .frame(width: size * 0.85, height: size * 0.15)
    .offset(y: size * 0.35)
    .blur(radius: size * 0.05)

// 2. 主体圆形（边缘厚度层）
Circle()
    .fill(color.swiftUIColor.opacity(0.8))
    .frame(width: size * 0.88, height: size * 0.88)

// 3. 表面层
Circle()
    .fill(color.swiftUIColor)
    .frame(width: size * 0.82, height: size * 0.82)
    .overlay(
        // 主高光（左上角）
        RadialGradient(
            colors: [Color.white.opacity(0.6), Color.clear],
            center: .init(x: 0.3, y: 0.25),
            startRadius: 0,
            endRadius: size * 0.35
        )
    )
    .overlay(
        // 次高光（右下角微弱反光）
        RadialGradient(
            colors: [Color.white.opacity(0.15), Color.clear],
            center: .init(x: 0.7, y: 0.75),
            startRadius: 0,
            endRadius: size * 0.25
        )
    )

// 4. 中心孔洞（带倒角）
Circle()
    .fill(
        RadialGradient(
            colors: [
                Color.black.opacity(0.9),
                Color.black.opacity(0.7),
                Color.gray.opacity(0.5)
            ],
            center: .center,
            startRadius: 0,
            endRadius: size * 0.14
        )
    )
    .frame(width: size * 0.28, height: size * 0.28)
    .overlay(
        // 孔洞边缘倒角
        Circle()
            .stroke(
                LinearGradient(
                    colors: [Color.white.opacity(0.3), Color.clear],
                    startPoint: .topLeading,
                    endPoint: .bottomTrailing
                ),
                lineWidth: size * 0.02
            )
    )

// 5. 外边缘描边
Circle()
    .stroke(
        LinearGradient(
            colors: [
                color.swiftUIColor.opacity(0.6),
                color.swiftUIColor.opacity(0.9)
            ],
            startPoint: .topLeading,
            endPoint: .bottomTrailing
        ),
        lineWidth: size * 0.04
    )
```

### BeadGridView.swift Canvas 绘制

使用 `context.drawLayer` 来管理绘制顺序和混合模式：

```swift
context.drawLayer { ctx in
    // 底部阴影
    let shadowRect = CGRect(x: x + cellSize * 0.08, y: y + cellSize * 0.75,
                            width: cellSize * 0.84, height: cellSize * 0.15)
    ctx.fill(Path(ellipseIn: shadowRect), with: .color(.black.opacity(0.2)))

    // 边缘厚度层
    let edgeRect = CGRect(x: x + cellSize * 0.06, y: y + cellSize * 0.06,
                          width: cellSize * 0.88, height: cellSize * 0.88)
    ctx.fill(Path(ellipseIn: edgeRect), with: .color(color.swiftUIColor.opacity(0.8)))

    // 表面层
    let surfaceRect = CGRect(x: x + cellSize * 0.09, y: y + cellSize * 0.09,
                             width: cellSize * 0.82, height: cellSize * 0.82)
    ctx.fill(Path(ellipseIn: surfaceRect), with: .color(color.swiftUIColor))

    // 主高光
    let highlightRect = CGRect(x: x + cellSize * 0.2, y: y + cellSize * 0.15,
                               width: cellSize * 0.4, height: cellSize * 0.35)
    ctx.fill(Path(ellipseIn: highlightRect), with: .color(.white.opacity(0.5)))

    // 中心孔洞
    let holeRect = CGRect(x: x + cellSize * 0.36, y: y + cellSize * 0.36,
                          width: cellSize * 0.28, height: cellSize * 0.28)
    ctx.fill(Path(ellipseIn: holeRect), with: .color(.black.opacity(0.8)))

    // 外边缘描边
    ctx.stroke(Path(ellipseIn: edgeRect),
               with: .color(color.swiftUIColor.opacity(0.7)),
               lineWidth: cellSize * 0.04)
}
```
